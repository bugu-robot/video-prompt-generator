# Repository instructions

Read README.md, STATUS.md and ARCHITECTURE.md before changing behavior. Keep work on a feature branch; never merge or deploy without explicit user approval.

- Keep all generation deterministic, browser-only and account-free. Do not add API keys, inference, server dependencies, runtime CDNs or telemetry.
- Keep provider capabilities in one dated registry, with website and API evidence separate. Never infer consumer support from an API source.
- Keep shared motion logic in the engine. Provider formatting must not silently change user intent.
- Keep Hong Kong Traditional Chinese UI and original English copying. Chinese output derives from the same plan; never fake translation or vision.
- Preserve local-only media, object URL disposal, no image/video-byte persistence, strict versioned import validation and atomic preset writes.
- Avoid claimed loop/geometry/360 guarantees or invented compatibility percentages. Respect immutable rotation/camera and identity constraints in variations.
- Preserve manual approval and generation kill switch in future Mochi integration; do not modify mochi-bot-v2 here.
- Keep Service Worker content-versioned, scoped to the base path and waiting for explicit update. No deployment job belongs in this mission.
- Run npm ci, typecheck, lint, all unit/browser tests, root/Pages builds and npm audit. Record exact counts/failures and real CI status. Do not label skipped critical tests as passed.
