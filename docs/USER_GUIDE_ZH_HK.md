# Video Prompt Generator 使用指南

這是一個完全在瀏覽器運作的影片提示詞工作台，適合 Little Jazz Stories 微動作循環、物件自轉和偶爾的電影感鏡頭。**程式不會生成影片，也不會登入 Flow 或 Grok。**

## 快速開始

1. 選擇或拖入 PNG、JPEG、WebP 原圖。檔案最多 25 MB、4,000 萬像素；程式只讀取本機圖片。
2. 手動選擇主體。需要更具體的 Mochi 描述時，選「自訂物件」，填寫英文及可選中文說明。沒有自動辨識或翻譯。
3. 選 Omni、Veo 或 Grok 及用途。預設是固定鏡頭、細微動作、首尾姿勢相配。
4. 選一個主要動作，再加入少量次要動作。沒有確認原圖元素時，英文使用條件式描述，避免憑空加物件。
5. 查看提示及相容性提醒。錯誤會禁止複製；JSON 仍可匯出作診斷。
6. 按「複製英文」，在外部網站自行提供原圖、選模型／時長，再貼上 prompt。這一步是否生成及消耗額度由你決定。

## 模式

| 模式 | 適合用途 | 主要控制 |
| --- | --- | --- |
| 環境微動作循環 | 咖啡廳、Mochi、雨窗、蒸氣、海浪等 Jazz 背景 | 微動作、環境動作、優先動作、鏡頭、循環策略 |
| 物件旋轉／鏡頭繞行 | 90°、180°、360° 物件展示 | 自轉或繞拍、角度、方向、軸、速度、幾何與構圖 |
| 電影感動態 | 一次性的慢推近、側移、環繞鏡頭 | 更多鏡頭路徑及所選主體／環境動作 |

物件自轉是物件郁、鏡頭固定；鏡頭繞行是鏡頭郁、物件固定。順逆時針以從正軸望向物件中心為準，Y 軸即由上方望下。動作幅度控制只適用於環境／電影模式；旋轉使用角度、速度及時長。

單張圖沒有可靠背面。多角度圖選項只是外部手動流程指引，不會自動傳圖；準確幾何請用真正 3D renderer。完整一圈須看整段影片驗收，不能只看首尾相似。

90°／180° 單向轉動的首尾方向不同，選循環時會提醒需要另外剪輯或設計回程；提示不會同時要求部分轉動又回到原方向。360° 持續循環只描述旋轉本身，不會另加環境動作。

旋轉模式會保留你在環境／電影模式選的微動作，但不會輸出或審核這些休眠中的動作；切換回去後會恢復選擇及真正的衝突提示。原設定、A／B／C 及供應商比較均按當前實際輸出的動作決定能否複製。

單向 90°／180° 自轉或繞行，不應把同一原圖填入外部網站的首尾兩個位置。如使用已確認支援的 Flow Frames，尾幀應是目標方向／視角的**不同圖片**；亦可不設定尾幀並選「不要求循環」。重複播放須另外設計回程或剪輯，程式不會自動更改角度、方向或動作。360° 完整一圈或真正回到開首姿勢的設定，才適合相同首尾圖的指引。Grok 首尾幀控制仍未核實，須先查看實際網站。

## 循環、原圖保留與音訊

「首尾姿勢相配」要求回到原來姿勢；「持續環境動作」保持接點動作；「交叉淡化友善」方便後期 dissolve。所有策略都不保證無縫。移動鏡頭會令首尾構圖不同，介面會提醒。

展開進階選項可調整身份、面部、比例、物件、構圖、光源、色彩、背景及風格保留。只會輸出適用項目。預設不要求音訊，但這不能保證靜音；配 Jazz 音樂時可在最後渲染移除生成音軌。

## English／繁中／中英對照與 A/B/C

英文是供應商原始提示。中文是同一動作計劃的解讀，不是 API 翻譯。所有複製按鈕一直複製英文。

A 減少次要動作，動作短暫疏落；B 保留完整選擇、自然節奏；C 延長動作可見時間，仍保留你選的幅度上限。A/B/C 不會添加新物件，亦不會改變身份、鏡頭、角度或方向。固定等速純旋轉沒有可變空間時，會明確說明三版 prompt 相同。

查看某一版後，JSON／文字匯出使用該版本的實際 Motion Plan。需要原設定時按「回到原設定」。Provider 比較保留同一意圖，再分別列出模型限制。Omni 先表達主要動作並自然連接同時發生的動作；Veo 先定鏡頭，再列主次動作、時長及接點；Grok 直接列動作與節奏，再指定鏡頭及接點。這是本機編排策略，不保證某一版本生成較好。

「精簡」用較短句子保留必要動作與約束；「平衡」使用完整易讀的動作控制；「詳細」加上與節奏、模式相符的中間姿勢或旋轉進程。三種長度都保留已選動作、身份、鏡頭及旋轉幾何，不會為縮短而刪走你的英文補充。

## 圖片框選

按「框選主體位置」後在原圖拖曳，也可展開「主體位置與場景補充」用百分比欄位操作。框選會轉成主體位置描述及 JSON metadata，**不是外部生成網站的 motion mask**。

更改主體類型、英文／中文主體描述、場景補充、所選動作（加入或取消）、原圖或框選後，需要重新確認原圖是否有相關元素。換入相同檔案也須重確認。切換供應商、語言、提示長度、鏡頭或幅度不會無故清除確認。套用預設或匯入設定亦須重確認。圖片內容不會存進 LocalStorage；重載／更新後要重新選圖。

## 我的預設與匯出

- 23 個內置預設可套用或複製；內置資料不會被改寫。
- 「另存設定」儲存新預設；「更新自訂」儲存編輯後設定。
- 支援重新命名、複製、刪除、單個／全部自訂 JSON 匯出。
- JSON 匯入先完整驗證；新增 ID，不覆蓋原有預設。格式／版本／數值不符會拒絕整批。
- 單次 JSON 及所有自訂預設的最終儲存／匯出資料，同樣限 **1 MiB（1,048,576 UTF-8 bytes）**，最多 100 個。中文字及 emoji 可能佔多個 bytes。即使每批可單獨匯入，合併總量過大仍會整批拒絕，已有資料完全保留。請先匯出備份，再刪掉不需要的預設或縮短備註；分批操作不會提高總量上限。
- 可匯出 prompt 文字或 Motion Plan JSON，後者供未來 Mochi Bot 整合。沒有自動生成或提交功能。

如舊有預設已過大、格式損壞或無法讀取，介面會顯示明確提醒，一般另存／更新／重新命名／刪除／合併匯入都會停止，避免覆蓋原資料。按「匯出原始預設備份」下載未經解析或修改的原文；檔案可能大於正常匯入上限，也可能不是有效 JSON。請保留這個檔案，修復格式或分拆為符合預設 schema、總量上限的檔案。確認備份已保存後，在「復原不可讀的自訂預設」勾選明確確認，再選修復檔案。復原會替換不可讀的自訂清單，沒放進修復檔案的項目仍在你的原始備份內；格式、大小、儲存配額或原始資料已變更等錯誤都不會修改舊資料。瀏覽器連原文都不允許讀取時，須先恢復該瀏覽器的儲存權限，不能假裝已匯出備份。

Motion Plan JSON 的物件 key 次序可不同，例如 `loopSettings` 的欄位次序；內容仍須完全吻合。陣列次序、值、schema、已登記的 compiler／能力快照組合、日期、原始英文提示及原審核仍作嚴格檢查。

舊版 compiler 1.0.0 設定匯入後，先按歷史版本驗證；介面會顯示原英文提示及新版 1.1.0 提示，未確認前不改目前設定。可先按「匯出原始設定檔」保存原文，再按「確認保留意圖並採用新編譯」。取消不改設定。原始 JSON／prompt 只保留在當次會話，不自動寫入瀏覽器；關閉前請另存備份。新匯出使用新版本、新 prompt 及新審核，不會把原 prompt 冒充新版本。尚未支援的版本／組合或被改動的 prompt 會拒絕，請保留原檔，勿自行改版本欄位。確認後須重新選圖及確認元素。

預設儲存在此瀏覽器的此網站來源，不會跨裝置同步。瀏覽器禁止儲存時可繼續使用記憶體版本，請匯出備份。重設不會刪掉已儲存自訂預設。

## 本機影片 QC

選擇已生成 MP4、WebM 或 MOV，最多 300 MB、10 分鐘。實際 codec 支援視瀏覽器而定。程式讀取時長／尺寸，擷取首幀及接近片尾的樣本，顯示 RGB／亮度差異。

12% RGB 差異是本機啟發式提醒門檻，不是供應商合格標準。低差異可能只是全段沒有郁；不能證明無縫、身份一致或 360° 完成。近尾樣本不是已驗證的精確最後一幀。

播放整段影片，逐項檢查身份、幾何、鏡頭、額外物件、循環、旋轉及自然度。未選項目保持「待檢查」。QC 報告不包含影片或擷取圖片內容。一般編輯 prompt、切換供應商／語言／長度、套用預設時，QC 影片的播放位置、播放或暫停狀態、速度、備註及驗收選項會保留。選另一影片或清除 QC 才會取消舊檢查及釋放舊影片資源；離開／重新載入後須重新選片。

## 安裝、離線與更新

用 production build 首次在線開啟，等「離線已就緒」才關網絡。Chrome／Edge 使用瀏覽器安裝功能；Safari 加入 Dock／主畫面。Service Worker 需要 HTTPS 或 localhost，不能以 `file://` 開啟。

新版本會顯示通知；只有按「儲存設定並更新」才重新載入。設定／預設保留，原圖／影片須重新選擇。開發模式不啟用 Service Worker。

本 app 沒有 backend、LLM、vision model、外部資源、帳戶或 API。使用供應商網站的條件、額度和功能須在該網站確認。提示符合指南不代表影片必定達標。
